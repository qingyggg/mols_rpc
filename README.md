### 🚀 mols_rpc：轻量高性能 Go RPC 框架
✨ 面向服务架构实践者的 Go 语言远程调用框架，灵活、简洁、可扩展

mols_rpc 是一个纯 Go 实现的轻量级 RPC 框架，支持 TCP 与 HTTP 双协议通信，内置服务注册、调用超时控制、编解码抽象、连接复用与基础负载均衡。它兼容标准库 net/rpc 接口，适用于微服务、内部服务通信及分布式系统场景。

🧩 核心特性
🔁 服务注册与自动分发：基于 reflect 实现服务动态注册与方法路由，支持多方法绑定。

⏱️ 调用超时控制：支持客户端与服务端调用超时设置，防止阻塞拖垮系统。

🔌 灵活通信协议：支持 tcp@ip:port 与 http://host:port 两种通信方式，适配不同部署环境。

🎛️ 编解码器抽象（Codec）：支持 gob 与 json，便于扩展 Protobuf、MsgPack 等高效序列化方案。

🧵 高并发连接复用：集成 goroutine pool（如 ants）实现连接高效复用与任务并发处理。
